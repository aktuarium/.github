# Aktuarium

**Aktuarium ([aktuarium.org](https://aktuarium.org))** adalah perangkat kerja aktuaria gratis untuk pengukuran kontrak asuransi menurut PSAK 117 (IFRS 17). Seluruh perhitungan berjalan di browser pengguna: tanpa akun, dan data input tidak dikirim ke server.

*Aktuarium (aktuarium.org) is a free actuarial workbench for PSAK 117 (IFRS 17) insurance contract measurement, running entirely in the browser.*

| Kelompok | Alat |
|---|---|
| Asumsi & produk | Discount Rate Lab (Smith-Wilson, NSS), Tabel Mortalita & Morbiditas, Pustaka Asumsi, Pustaka Produk |
| Pengukuran produk | GMA, PAA, VFA, dengan berkas Excel berformula |
| Valuasi & analisis | Valuasi Polis, Skenario & Sensitivitas, CSM Roll-Forward |
| Referensi | Regulation Desk, Belajar PSAK 117, Glosarium aktuaria, AI Assistant |

**Aktuarium bukan aktuaria.** Aktuaria adalah bidang ilmunya; Aktuarium adalah nama situs alat kerja ini.
